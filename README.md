# 🚀 GameOptimizer CLI

Script leve em PowerShell projetado para entusiastas de PC gaming e emulação que procuram reduzir o *stuttering* e extrair o desempenho máximo do hardware antes de iniciar jogos exigentes.

---

### ⚡ Funcionalidades

- **Plano de Energia:** Ativa instantaneamente o perfil de Alto Desempenho do Windows.
- **Limpeza de Cache de Shaders:** Remove ficheiros temporários das pastas de cache da GPU (NVIDIA) e DirectX para prevenir quebras de fotogramas causadas por dados corrompidos.
- **Restauração Rápida:** Repõe o plano equilibrado de energia após o encerramento da sessão de jogo.
- **Nativo e Leve:** Criado em PowerShell, sem necessidade de instalar pacotes adicionais ou programas pesados em segundo plano.

---

### 🛠️ Como Utilizar

1. Baixe o arquivo `optimizer.ps1`.
2. Clique com o botão direito no arquivo e selecione **Executar com o PowerShell** (ou execute através do terminal como administrador).
3. Selecione a opção pretendida no menu numérico interativo.
